## ✨ Key Features

- **⚡ Instant Real-Time Search:** Search through snippet titles and actual source code on the fly.
- **🏷️ Language Filters:** Filter components by **HTML/CSS**, **JavaScript**, and **C++**.
- **🎥 Dedicated Media Previews:** Manual video controls (Play/Pause) with zero distracting autoplay loops.
- **❤️ Persistent Like Engine:** LocalStorage-backed like counter with reactive heart animations.
- **📋 1-Click Code Copy:** Instant clipboard export with real-time feedback badges.
- **🔒 Integrated Admin Panel:** Protected project deployment and card manager powered by local browser storage.
- **🎨 Obsidian Cyberpunk Theme:** Minimalist geometric vector branding, glowing neon orbs, and glassmorphic UI.

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3 (Modern Flexbox & CSS Grid, Glassmorphism)
- **Scripting:** Pure JavaScript (ES6+, DOM Manipulation)
- **State Persistence:** Browser `LocalStorage` API
- **Deployment & Hosting:** [Vercel](https://vercel.com) & [GitHub Pages](https://pages.github.com)
